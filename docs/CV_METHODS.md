# Что изменилось после первой версии

Раньше преобразование яркости действовало на весь лист. Это усиливало текст,
но вместе с ним серый фон. Новая ветка оценивает фон RGB отдельно, затем усиливает
разницу между бумажным фоном и наблюдаемыми чернилами.

1. Уменьшение рабочего изображения до длинной стороны не более 900 пикселей.
2. Морфологическое замыкание эллиптическим ядром и Gaussian smoothing дают
   приближение фона B. Замыкание применяется к оценке фона, не к итоговым буквам.
3. Нормализация каждого канала: N = clip(I / max(B, 32), 0, 1).
4. Плотность чернил D = 1 - N. Усиление D' = 1 - (1-D)^g,
   g=2.6 для balanced и 4.5 для detail при strength=1.
5. Положительные тёмные остатки относительно Gaussian sigma=0.8 и 2.4
   дают двухмасштабную добавку. Она не выбеливает сердцевину тонкого штриха.
6. Возврат к RGB, ограничение диапазона, возврат исходных пикселей по маске.

В ink_study разность каналов относительно фона усиливает цветные чернила.
Это не сегментация печати и не восстановление исходной краски.
Ни пороговая бинаризация, ни удаление маленьких компонент не применяются.

Границы метода: большие тёмные участки могут нарушить оценку бумаги; цветной
фон может попасть в маску целиком; сильное усиление поднимает шум, JPEG-артефакты
и паразитный рисунок бумаги. Буквы с полностью утраченными штрихами остаются
неоднозначными. По картам изменений нельзя доказать правильность букв.

CLAHE оставлен в фото-ветке. Сильное локальное выравнивание гистограммы на
выцветших копиях способно усилить бумажный шум. Новые CV-кандидаты используют
явную модель фона вместо автоматического выбора по «резкости».
