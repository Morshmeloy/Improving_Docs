# Сохранение исходного начертания и размера

Замечание пользователя подтвердилось: режим `verified_label_text` подменял
растр букв наборным шрифтом и растягивал его по прямоугольнику. Шрифт отличался,
а увеличение высоты области очистки дополнительно увеличивало высоту букв.
Прежний профиль сохранён как эксперимент, но для текущего документа следует
использовать `profiles/va103_source_typography.json`.

## Новый режим `source_guided_label`

Источник геометрии — оригинальный растр документа. Не устанавливаем и не
подбираем похожий шрифт, не набираем надпись заново, не масштабируем исходные
буквы. Образец служит подтверждением формулировки и небольших разрывов.

1. OpenCV выделяет видимые малонасыщенные штрихи исходника (яркость меньше
   210, разброс RGB меньше 35). Компоненты меньше трёх пикселей отбрасываются.
2. Из этих штрихов вычисляется исходный пиксельный прямоугольник надписи.
3. Маска чернил образца масштабируется в этот прямоугольник для сравнения;
   исходные буквы при этом не меняют масштаб. Проверяются сдвиги образца
   от -2 до +2 пикселей по двум осям.
4. Добавить пиксель можно только там, где его одновременно предлагают образец
   и морфологическое закрытие исходных штрихов ядром 3x3. Добавления остаются
   внутри исходного прямоугольника, их число ограничено 25% найденных штрихов.
   При недостаточной поддержке образца (меньше 0.55) добавлений нет.
5. Наблюдаемые исходные штрихи затемняются по их собственной интенсивности
   с коэффициентом 3.4. Бумага не заменяется белым прямоугольником. Цветные
   пиксели, не вошедшие в маску штрихов, сохраняются из исходника.

Это компьютерное зрение и локальная реконструкция штрихов, а не генерация
шрифта. Для индивидуального содержания остаётся прежняя DocRes-основа.
Внутри выбранных статических надписей основа заменяется обработкой оригинального
растра, чтобы убрать привнесённую ранее геометрию букв.

## Запуск для проверенного примера

```powershell
cd C:\Projects\Improving_Docs
git pull --ff-only
.\.venv-ai\Scripts\python.exe template_restore.py --source "input\Сертификат на выключатели ВА-103_ПЛОХОЙ.pdf" --base "output\va103_whole\page_0001_reconstructed.png" --reference "input\template.png" --profile "profiles\va103_source_typography.json" --output "output\va103_original_type_001" --dpi 200 --rotate 180
Start-Process "output\va103_original_type_001\comparison.html"
```

Замените пути на фактические. Используйте прежнюю нейросетевую основу целой
страницы, а не PDF с уже подменённым шрифтом. Папка результата должна быть новой.
Исходник и образец привязаны к профилю SHA-256. Профиль рассчитан на конкретную
страницу ВА-103; для других документов нужно заново проверить области.

## Проверено

На реальной странице обработаны 22 внутренних статических элемента. Для всех
22 измеренные границы наблюдаемых штрихов сохранены; добавлены 2623 пикселя
локальных разрывов. Нет нового наборного шрифта и масштабирования исходных букв.
Все пиксели вне выбранных областей и внутри дополнительных защищённых областей
совпадают с прежней нейросетевой основой. PDF проверен на совпадение растра с PNG
и просмотрен после рендеринга. 33 теста прошли на Linux.

В сравнении представлены три колонки: исходник, предыдущая версия с наборным
шрифтом и исправленная версия. Кадры имеют одинаковый масштаб. Рамка и два
верхних декоративных заголовка остаются из предыдущего переноса образца;
исправление касается внутренних служебных надписей и знака EAC.

## Ограничения

Границы считаются по видимым исходным штрихам, а не по неизвестным утраченным
пикселям. Это не доказательство полного восстановления букв. Остаточная
зернистость и некоторые разрывы видны; увеличивать размер или подменять
шрифт ради их скрытия больше не следует. Поддержка образца основана на
совпадении пиксельных масок, не на распознавании отдельных букв. Если исходная
надпись полностью исчезла, режим оставит её без изменений и запишет
`no_source_ink`, а не вставит чужое начертание.
