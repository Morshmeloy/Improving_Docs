# Нейросетевая маска и чёрная реконструкция выбранных областей

## Что выяснилось на исходном ВА-103

В присланном отчёте старой обводки `drawn_pixels=0`, `bridge_pixels=0`;
в overlay нет зелёных или красных пикселей. Чёрный слой не был построен.
Старый код всё равно применял контурный фильтр ко всей странице и возвращал успех.
Причину пустого слоя без JSON выбранных областей нельзя установить окончательно:
возможны отсутствующие области, ручные блокировки или отсутствие подходящих штрихов.

Исправлено: без областей для точного имени файла/страницы — ошибка;
вне выбранных областей пиксели сохраняются; отсутствие штрихов явно помечается.

DocDiff успешно отработал, но не дал достаточного восстановления выцветания.
DocRes appearance также слаб на бледных заголовках. Прямой DocRes binarization
удаляет бледный заголовок и части подписи — этот результат нельзя использовать
как замену исходной странице.

## Новая последовательность

1. Для каждой выбранной области оценивается цвет бумаги и усиливается плотность
   чернил (gain 1..20). Это классическая предобработка, не нейросеть.
2. В усиленную область подаётся **готовая обученная DocRes** в задаче binarization.
   Вход: BGR + три канала авторского prompt (Sauvola threshold, Sobel, binary prior).
   Первые два выходных канала интерпретируются как логиты классов ink/background.
3. Из нейросетевой маски удаляются компоненты менее 3 пикселей, строится skeleton.
   Пары направленных концов на расстоянии до `--max-gap` соединяются линиями.
4. Маска и короткие новые соединения рисуются чёрным поверх оригинала. Ничего
   из исходных штрихов не стирается. Цветные пиксели по RGB-эвристике и ручные
   блокировки сохраняются точно. Области вне выбранных прямоугольников неизменны.

Это **редактируемая реконструкция**, включая предположительные соединения.
Модель может ошибаться в форме букв; это не OCR и не доказательство подлинности.
Качество зависит от gain и масштаба. Увеличение gain может превратить бумажный шум
в чернила. Не следует автоматически считать такой PDF финальной версией.

В нейросетевой mask-файл входят и ошибочно отброшенные штрихи; он диагностический.
В составной результат добавляются только чёрные штрихи, исходник сохраняется.

## Windows

Обновите проект и установите DocRes в имеющееся окружение:

```powershell
git pull --ff-only
.\setup_docres_windows.bat
```

Создайте JSON `ink_regions.json`, используя **точное имя исходного файла**.
Координаты относятся к изображению **после поворота**, X0 Y0 X1 Y1:

```json
{
  "Сертификат на выключатели ВА-103_ПЛОХОЙ.pdf": {
    "1": [
      {"box": [0.24, 0.07, 0.75, 0.112], "gain": 10},
      {"box": [0.38, 0.128, 0.65, 0.15], "gain": 8},
      {"box": [0.35, 0.855, 0.73, 0.975], "gain": 5}
    ]
  }
}
```

Это области заголовка, серии и части подписи/серой печати именно присланного ВА-103.
Для другого документа координаты нужно выбирать заново; JSON селектора из прежнего
режима находится в исходной ориентации и не переносится автоматически при повороте.

```powershell
.\.venv-ai\Scripts\python.exe ink_reconstruct.py '.\input\Сертификат на выключатели ВА-103_ПЛОХОЙ.pdf' --regions .\ink_regions.json --rotate 180 --dpi 300 --threads 4 --output .\output\ink_001
Start-Process .\output\ink_001\comparison.html
```

Результат: `reconstructed_draft.pdf`, полный исходный PNG и результат,
overlay (зелёный — нейросетевая маска, красный — соединённые разрывы),
а также исходная/усиленная область и нейросетевая маска для каждого прямоугольника.
В отчёте — число рисованных пикселей и соединений, контроль цвета и областей.
Каждый встроенный растр итогового PDF проверяется на равенство сохранённому PNG.
Папка результата не перезаписывается. Оригинал PDF копируется и не изменяется.

Поддерживается один документ с несколькими страницами за запуск. Пакетный нейросетевой
режим будет добавлен после оценки качества; существующие пакетные `.bat` его не вызывают.

## Проверка первого черновика ВА-103

При 300 DPI в трёх выбранных областях добавлено 102670 чёрных пикселей.
Алгоритм коротких соединений в этом запуске не нашёл подходящих пар: 0 мостиков.
Заголовок, серия и серая печать стали заметнее, но есть рваные контуры и грубые
утолщения. Это не финальная версия и не полное восстановление: рамка и остальные
бледные поля в этом опыте не обработаны. Пиксели вне областей совпадают точно.
PDF перепроверен по встроенным растрам и отдельно отрендерен Poppler.
23 теста прошли, включая ошибку при пустых областях, неизменность вне области
и сохранение цветных штрихов. Оригинал PDF сохранён и его SHA-256 не изменился.
