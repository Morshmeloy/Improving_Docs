# Проверки версии 2 — 2026-10-06

Локально: Python 3.12, Linux; unittest discover — 8 тестов.
Это не означает, что установка/GUI на Windows уже проверены. CI настроен для
Windows/Ubuntu; его итог следует смотреть в GitHub Actions.

## Контролируемый синтетический пример

Градиент светлой бумаги 170..250, горизонтальные линии темнее бумаги на
12 и 8 уровней яркости. Размер 640x360, без случайного шума, сила CV = 1.
Диапазон фона измеряется на внутреннем отрезке строки без линий. Контраст
измеряется между известной линией и соседним фоном, без OCR.

| Вариант | Диапазон фона, уровни | Контраст линии, уровни |
|---|---:|---:|
| Исходник | 70 | 12.00 |
| readable (v1) | 144 | 22.65 |
| cv_balanced | 2 | 37.12 |
| cv_detail | 3 | 61.01 |

Эти числа характеризуют только этот пример. На скане с шумом усиление может
ухудшать распознавание. Достоверного процента улучшения реального текста нет:
чистый оригинал и ручная транскрипция не предоставлены.

## Сохранение и защита

Синтетические тесты проверяют сохранённые PDF через извлечение RGB-растра,
точность ручных/цветовых масок и отказ при несовпадении пикселей. Обработка
повреждённого файла не останавливает четыре корректных входа (PDF, PNG, JPEG,
многостраничный TIFF). Повторный запуск не перезаписывает результат.

При проверке полноразмерного реального скана один первоначальный PDF-кандидат
имел некорректную структуру xref. Для новых результатов отключено перенумерование
xref при garbage collection (`garbage=0`), а после сохранения каждого PDF теперь
обязательно проверяются число страниц и совпадение всех RGB-пикселей с PNG.
Файл с ошибкой не публикуется как успешный результат. Причина сбоя на уровне
библиотеки не установлена; проверка не зависит от предположения о причине.

Точная защита относится к пикселям исходного растра при заданном DPI. Извлечь
незаметно утраченные детали или подтвердить подлинность подписи этот тест не может.

## Оставшиеся ограничения

- Нейросетевая модель восстановления ещё не подключена.
- Тест OCR русских документов здесь не проведён: установлен только английский
  языковой пакет. OCR-аудит требует отдельной установки rus+eng.
- Усиленный вариант вне ручных масок меняет подписи и штампы; нужно сравнение.
- Для очень длинных PDF требуется работа над дисковой потоковой сборкой,
  сейчас пять кандидатных PDF одного документа удерживаются в RAM.
