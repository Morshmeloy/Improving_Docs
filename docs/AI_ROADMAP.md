# Нейросетевое восстановление: следующий эксперимент

## Обновление: добавлен DocDiff CPU

Теперь доступен отдельный исполняемый нейросетевой эксперимент `ai_restore.py`
с установкой готовых весов через `setup_docdiff.py`. Инструкция: [AI_CPU.md](AI_CPU.md).
Это устранение размытия выбранного фрагмента/страницы, не окончательная версия
пакетного восстановления. Ниже сохранён прежний план DocRes для следующего сравнения.

Нейросеть не запрещена. В версии 2 исполняются классические CV-методы и
опциональный внешний OCR. Веса DocRes не включены и не запускались.
Не следует выдавать наличие этого плана за готовую нейросетевую интеграцию.

Кандидат — DocRes, документная модель для dewarping, deshadowing, appearance
 enhancement, deblurring и binarization. Начать с appearance enhancement и
 deshadowing, проверить сохранение геометрии. Ссылка на официальный код:
https://github.com/ZZZHANG-jx/DocRes
Статья: https://arxiv.org/abs/2405.04408

Почему не начинать с генеративного апскейлера фотографий: правдоподобная форма
штриха не доказывает, что она была в оригинале. Даже специализированная модель
может изменить мелкие буквы, подпись и печать. Тестировать нейросеть как отдельный
кандидат, а не бесконтрольно заменять исходник.

## Порядок интеграции

1. Зафиксировать commit модели, контрольную сумму весов и условия лицензии.
   Проверить зависимости для конкретного ПК; на ИИ-сервере отдельно проверить
   поддержку имеющихся GPU используемой сборкой PyTorch. Без обязательного CUDA.
2. Запускать локально, без отправки документов наружу. Сохранить исходник.
3. Обработка страниц/тайлов с перекрытиями, контролем границ и RAM/VRAM.
4. Отдельный результат neural_experimental. Копировать защищённые области из
   исходного растра после модели, строго без изменения размеров/координат.
5. Проверить полный цикл PNG → PDF → извлечённый растр и маски.
6. Сравнить с cv_detail по известному чистому оригиналу на синтетических
   деградациях и по ручной транскрипции реальных сканов.

## Данные и измерения

Нужны чистые и испорченные пары (размытие, слабый контраст, повторное копирование,
неравномерная засветка, JPEG), с цветными и серыми печатями/подписями. Разделять
train/validation/test по исходному документу, а не по его ухудшенным копиям.

PSNR/SSIM использовать только если есть соответствующий чистый оригинал.
OCR CER/WER вычислять относительно ручной транскрипции; confidence — лишь
сигнал для просмотра. Проверять сохранение тонких линий и отсутствие слияний
букв отдельно. Не оптимизировать только визуальную белизну или Laplacian variance.

Финальная приёмка: визуальная проверка критичных полей, подписей и печатей,
пиксельная идентичность всех заблокированных областей, отсутствие новых/исчезнувших
штрихов вне них по сравнению с доступными наблюдениями. Если штрих отсутствует
в наблюдении, невозможно доказать его восстановление по одному скану.

До такой проверки нейросетевой результат остаётся исследовательским.
