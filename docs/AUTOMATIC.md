# Один запуск, два выбора файлов

```powershell
cd C:\Projects\Improving_Docs
git pull --ff-only
.\run_windows.bat
```

Первый запуск автоматически установит зависимости и загрузит готовые модели.
Выберите документы в первом окне (можно выделить несколько файлов).
Затем выберите образец в следующем окне. **Отмена** во втором окне означает
«без образца», а не отмену обработки.

Все страницы PDF и TIFF, затем все следующие документы обрабатываются
последовательно, без вопросов и промежуточных редакторов. Один образец
применяется ко всем выбранным документам, когда его структура соответствует
странице. Многостраничный PDF также можно использовать как образец.
Если нужны разные образцы для разных групп, запустите программу ещё раз
с другой группой документов и другим образцом.

В конце открывается общая страница результатов. В каждой папке документа:

- `restored_draft.pdf` — улучшенная растровая копия;
- `comparison.html` — оригинал рядом с результатом;
- `page_..._final.png` — отдельные страницы;
- `report.json`, маски и изображения изменений — диагностика.

Папки создаются автоматически внутри `output/auto_...`.
Оригиналы сохраняются и не перезаписываются. Ошибка одного файла записывается
в общий отчёт, после чего скрипт переходит к следующему.

## Что автоматизировано

1. EasyOCR CRAFT и кириллическая модель распознавания, `ru` + `en`, на CPU:
   сравнение четырёх поворотов каждой страницы и обнаружение надписей.
2. Усиление слабых чернил относительно локального фона бумаги.
3. DocRes binarization на всей странице и соединение небольших разрывов
   штрихов. Модель загружается один раз на пакет.
4. Сопоставление страниц образца по общим постоянным названиям полей.
5. Распознавание полного названия поля в исходнике и образце, подбор размера
   по видимым штрихам оригинала, отрисовка Tinos. Если OCR объединило название
   с реквизитами в одну строку, участок не перепечатывается.
6. Совмещение золотого орнамента по нескольким постоянным OCR-опорам,
   только на полях страницы, с сохранением исходных тёмных штрихов.
7. Проверка сохранности пикселей вне маски добавленного каркаса и точного
   совпадения PNG с изображениями, встроенными в PDF.

Образец участвует в OCR и компьютерном зрении; он не подаётся в DocRes как
второй вход нейросети. Даты, организации, номера, фамилии, реальные подписи
и печати из образца не копируются. Цветные исходные чернила защищаются
эвристикой; это не семантическое распознавание подписи. Монохромные росчерки
могут измениться при восстановлении штрихов всей страницы.

Распознавание мелких, сильно потёртых или перекрытых надписей остаётся
ограничением. Названия полей определяются по встроенному словарю известных
постоянных формулировок сертификата; для других форм используется DocRes,
а неизвестный служебный текст автоматически не перепечатывается. Если
образец не совпадает хотя бы по трём постоянным названиям, остаётся только
нейросетевая обработка исходника. Надпись с ненадёжной геометрией или
перекрытием индивидуального текста также остаётся без перепечатки.

Для уже проверенной пары ВА-103 и предоставленного образца используется
сохранённая геометрия и подобранный стиль. Она активируется только при
точном совпадении SHA-256 **обоих** файлов. Новые документы никогда не получают
эти координаты по имени файла или похожему внешнему виду.

## Дополнительный запуск без диалогов

```powershell
.\.venv-ai\Scripts\python.exe batch_review.py "input\one.pdf" "input\two.pdf" --reference "samples\form.pdf"
```

Без образца достаточно перечислить документы. Можно передать папку:

```powershell
.\run_windows.bat "input"
```

Ручной редактор остался отдельным расширенным инструментом:
`manual_batch_review.py`. Он не вызывается из обычного режима.

Источники моделей:
[EasyOCR](https://github.com/JaidedAI/EasyOCR),
[документация OCR](https://www.jaided.ai/easyocr/documentation/),
[DocRes](https://github.com/ZZZHANG-jx/DocRes).
