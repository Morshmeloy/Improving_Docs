# Обводка чёрным и соединение разрывов

Этот режим добавляет новый рисунок поверх скана. Развивается по отдельной ветке
классического CV, без генеративного изменения остального текста.

1. Оценить бумагу и получить слабые штрихи по плотности RGB.
2. Отобрать компоненты для слоя рисования (от 7 пикселей), оставить исходник.
3. Проредить найденные области до линий алгоритмом Zhang-Suen.
4. Найти концы линий и их направление по соседним пикселям.
5. Соединить близкую пару, если оба конца направлены друг к другу.
6. Нарисовать скелет и соединения чёрным. Каждый конец участвует максимум
   в одном соединении. Предел расстояния, толщину и чувствительность можно менять.

Максимум 6 пикселей при 300 DPI — около 0.51 мм между концами. Это не доказательство
правильности предполагаемого соединения. Снижение threshold добавляет больше
бледных линий и бумажного шума. `--line-width 2` усиливает обводку, но может
склеивать соседние штрихи. `--max-gap 0` отключает соединения, оставляя обводку.

В выходной папке: `redrawn.pdf`, исходный файл, исходные/обведённые PNG,
`drawing_overlay` (зелёная обводка и красные соединения), координаты соединений
в `report.json` и сравнение HTML. Сохранённый PDF проверяется на совпадение растра
с PNG. Ошибка одного документа не останавливает пакет. Оригиналы не перезаписываются.

Для выбора областей: `select_redraw_regions_windows.bat`. Для пакетного запуска:
`run_redraw_windows.bat`. Требуется выполнить обычный `setup_windows.bat`.
GUI выбора областей на пользовательском Windows ПК ещё не проверен.

Команда:

```bash
python redraw_batch.py input --output output/draw_001 --redraw-regions redraw_regions.json --max-gap 6 --threshold 0.04
```

JSON имеет форму `filename -> page number -> normalized [x0,y0,x1,y1] boxes`.
Вместо областей можно явно указать `--redraw-all`, но это будет обводка всего
листа, включая штампы, буквы и шумы. Дополнительный `--regions protected_regions.json`
возвращает точные исходные пиксели в защищённых прямоугольниках, перекрывая рисование.

Фон и остальные области получают умеренное контрастное усиление, поэтому результат
не идентичен исходнику даже вне областей обводки. Карта рисования показывает именно
чёрную обводку/соединения, а не все тональные изменения.

Испытание на сертификате: на двух страницах добавлено 44 и 35 коротких соединений
в выбранных областях. Порог 0.04, толщина 1 px. Сохранённый PDF проверен и обе
страницы просмотрены после рендеринга Poppler. Для этого скана чистый оригинал
отсутствует: добавленные соединения оценены визуально, не подтверждены эталоном.

Четыре новых теста: соединение направленных концов; отсутствие бокового склеивания
параллельных линий; чёрная обводка и точные блокировки; продолжение пакета после
ошибочного файла. Всего 16 тестов.
