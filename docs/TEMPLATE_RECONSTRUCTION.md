# Восстановление каркаса по предоставленному образцу

Расширенная версия с внутренними полями: [STATIC_FORM_ATLAS.md](STATIC_FORM_ATLAS.md).
Описание ниже относится к первому профилю рамки и заголовков.

Пример пользователя используется как источник постоянных частей бланка.
Содержимое образца отличается, поэтому переносить всю страницу, его подписи,
печати, номера, даты или сведения о продукции нельзя.

Текущий конвейер:

1. `ink_reconstruct.py --whole-document` обрабатывает исходник через усиление
   слабых чернил, обученную DocRes-маску и реконструкцию штрихов.
2. `template_restore.py` берёт полученный PNG как основу, а предоставленный
   образец — только для явно перечисленных частей каркаса.
3. OpenCV совмещает четыре угла каждого разрешённого фрагмента. Области заданы
   вручную в профиле: это контролируемое геометрическое совмещение, а не
   автоматическое нейросетевое распознавание шаблона. Новая нейросеть на этом
   этапе не запускается; ИИ применяется на предыдущем этапе.
4. Защищённое содержимое и все пиксели вне областей переноса должны в точности
   совпадать с нейросетевой основой. Пересечение переноса с защищённой областью
   вызывает ошибку. Смысловую правильность основы эта проверка не доказывает.

## Профиль испытанного примера

`profiles/va103_template.json` рассчитан на конкретный исходник ВА-103,
повёрнутый на 180 градусов и растрированный при 200 DPI, и конкретный пример
пользователя. Перед использованием другого образца или другого документа
необходимо создать собственный профиль с правильными координатами. Профиль
примера привязан SHA-256 к исходнику и образцу: другой файл будет отвергнут.
В собственном профиле поля `source_sha256` и `reference_sha256` можно задать
для такой же проверки; они необязательны.

Переносится:

- плашка «ЕВРАЗИЙСКИЙ ЭКОНОМИЧЕСКИЙ СОЮЗ»;
- заголовок «СЕРТИФИКАТ СООТВЕТСТВИЯ»;
- орнамент левой, правой и верхней границ;
- нижняя граница, повторённая из чистого верхнего фрагмента орнамента.

Нижняя рамка — реконструкция рисунка, а не возвращённые оригинальные пиксели.
Микропечать внизу образца не переносится. Логотип EAC внутри страницы,
рукописные подписи, печати, сведения и номера остаются из обработанного исходника.
Подпись из чужого документа не служит образцом для восстановления росчерка.
Цвет каркаса здесь взят из примера; совпадение с историческим цветом оригинала
не доказано. PDF помечен как отредактированный черновик.

## Windows PowerShell

Сохраните собственный образец как `input\template.png`. Сначала создайте
нейросетевую основу командой из `INK_RECONSTRUCTION.md`. Затем укажите её PNG:

```powershell
cd C:\Projects\Improving_Docs
git pull --ff-only
.\.venv-ai\Scripts\python.exe template_restore.py --source "input\Сертификат на выключатели ВА-103_ПЛОХОЙ.pdf" --base "output\va103_whole\page_0001_reconstructed.png" --reference "input\template.png" --profile "profiles\va103_template.json" --output "output\va103_template_001" --dpi 200 --rotate 180
Start-Process "output\va103_template_001\comparison.html"
```

Замените пути на свои. Папка результата должна быть новой. PNG основы должен
совпадать с растром исходника по размерам при выбранных `--dpi` и `--rotate`.
Команда обрабатывает одну указанную страницу (`--page 1` по умолчанию), а не
молча объявляет весь многостраничный PDF восстановленным. Для других страниц
используйте отдельные подходящие профили и основы.

## Как предоставить другой шаблон

Профиль JSON содержит `schema: 1`, `protected` и `regions`. Координаты
нормализованы от 0 до 1, начало в левом верхнем углу. Все координаты целевого
документа задаются после поворота. Для каждой области укажите:

- `name`: понятное имя;
- `kind`: `static_heading` или `ornamental_frame`;
- `target`: `[x0,y0,x1,y1]` на документе;
- `reference`: такой же прямоугольник на образце;
- `mode`: `projective` по умолчанию; `tile_x` только для повторяемого орнамента.

`protected` обязательно включает всё переменное содержимое, подписи, печати и
номера. Система доверяет ручной классификации статических областей; она сама
не определяет, где написаны имена или реквизиты. По этой причине автоматический
поиск в интернете и автоматическое принятие найденного шаблона не включены.
Пользователь предоставляет подходящий образец, затем проверяет карту переноса.

## Проверка результата

`comparison.html` показывает основу, результат и карту переноса. Розовым
выделены пиксели образца. `report.json` хранит SHA-256 исходника, основы,
образца и профиля, геометрию каждого преобразования и результат проверки
точного сохранения содержимого. `transferred_mask.png` позволяет независимо
проверить область изменений. Растр PDF сверяется с сохранённым PNG.

Испытано на Linux: реальный пример пользователя и весь набор из 28 тестов.
Тест с полностью чёрным чужим образцом проверяет, что его содержание не может
попасть за пределы разрешённого каркаса; проверяются конфликт с защищённым
содержимым и повторение орнамента. Windows-команда пока проверена только по
синтаксису и совместимости используемых библиотек, не на ПК пользователя.
