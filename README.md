# Improving Docs — автоматическое восстановление

Основной режим: **выбрать документы → выбрать образец, если есть → получить результат**.
Прямоугольники, JSON-профили, номера страниц, поворот и параметры нейросетей
в обычном запуске вводить не нужно.

В PowerShell из папки проекта:

```powershell
git pull --ff-only
.\run_windows.bat
```

Запуск сам устанавливает недостающие зависимости при первом использовании.
Модели загружаются один раз; далее обработка выполняется локально на CPU,
в том числе на компьютере с AMD Radeon. Первая установка требует интернета.

1. В первом окне выберите один или несколько PDF, PNG, JPEG, TIFF, BMP, WebP.
2. Во втором выберите образец / читаемый оригинал формы. Если его нет,
   нажмите **Отмена** — документы всё равно будут обработаны.
3. Дождитесь обработки: страницы и документы идут по очереди автоматически.
   В конце откроется сравнение, ссылки на готовые PDF и папку результатов.

Скрипт сам проверяет четыре ориентации каждой страницы через EasyOCR,
восстанавливает чернила по всей странице нейросетью DocRes, распознаёт
постоянные названия полей и сопоставляет страницы образца. Для найденных
надписей использует Tinos с размером по видимым штрихам исходника.
Каркас дополняется только при уверенном совпадении постоянных надписей;
реквизиты, фамилии, даты и росчерки из образца не копируются.

Обработка автоматическая, но качество распознавания не гарантировано:
если надпись или соответствие образцу не распознаны, участок остаётся
результатом восстановления штрихов. Возможны ошибки в реконструкции.
Результат — редактированная растровая копия; оригиналы не перезаписываются.
