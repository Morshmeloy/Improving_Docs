## Быстрый запуск Windows (Python 3.12)

1. Скачайте репозиторий и распакуйте.
2. Запустите `setup_windows.bat`.
3. Положите PDF/PNG/JPEG/TIFF/BMP/WebP в `input`.
4. Для точного сохранения подписей запустите `select_regions_windows.bat`,
   выделите все подписи и печати прямоугольниками на каждой странице.
5. Запустите `run_windows.bat`.
6. Откройте `comparison.html` внутри папки документа в `output/run_...`.

Оригиналы не перезаписываются. PDF и многостраничные TIFF обрабатываются
постранично. Ошибка одного файла не останавливает следующие; код возврата 1
означает, что часть пакета не обработана. Каждый документ завершается атомарно.

## Запуск из терминала

```bash
python -m venv .venv
# Linux:
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python enhance_batch.py input --output output/run_001 --regions protected_regions.json
```

Без ручных областей:

```bash
python enhance_batch.py input --output output/run_002
```

Исследовательский вариант цветных чернил и увеличение силы CV-фильтров:

```bash
python enhance_batch.py input --output output/run_003 --ink-study --strength 1.3
```

`--strength` (0.25–2) меняет только новые CV-варианты. Большая сила усиливает
шумы и утолщает видимые штрихи. `--dpi 300` управляет растрированием PDF;
повышение DPI не возвращает отсутствующие в скане данные. `--max-megapixels 40`
ограничивает размер страницы (не полный объём RAM). `--recursive` включает
подпапки. На сервере с большим числом страниц нужно контролировать RAM и диск:
одновременно удерживаются PDF-кандидаты одного документа.

## Варианты

| Файл PDF | Обработка | Защита |
|---|---|---|
| `enhanced_safe.pdf` | Старый бережный контраст | Цветная эвристическая маска + ручные области |
| `enhanced_readable.pdf` | Старый сильный контраст | Та же защита |
| `enhanced_cv_balanced.pdf` | Оценка бумаги по RGB, выравнивание фона, усиление плотности чернил | Та же защита |
| `enhanced_cv_detail.pdf` | Более сильное усиление + детали на двух масштабах | Та же защита |
| `enhanced_ink_study.pdf` | Дополнительное усиление цветных чернил (`--ink-study`) | Только ручные области; цвета изменяются |

Для обычных фотографий: `--mode photo`. Документные фильтры предполагают
светлую бумагу и тёмные чернила; цветные фото следует обрабатывать режимом photo.

Для каждого варианта сохраняются PNG, отдельная маска защищённых пикселей,
карта изменений (красный = величина изменения) и метрики в `report.json`.
Исходник и его SHA-256 сохраняются рядом. Ни одна метрика не доказывает
смысловую идентичность текста и подписи.

**Пиксельная защита:** ручные прямоугольники копируются из исходного растра точно,
во всех вариантах. Для PDF это растр страницы при выбранном DPI, а не байты
исходного PDF. Цветовая эвристика не распознаёт подпись или печать как объект;
серые, чёрные и очень бледные цветные штрихи может не защитить. Для гарантий
нужны ручные области. В защищённой области бледные чернила остаются бледными.
Перекрывающий подпись текст также не улучшается. Отдельный исследовательский
вариант без прямоугольников позволяет увидеть усиление подписи, но гарантия
пиксельной идентичности тогда отсутствует.

Новые PDF — растровые производные: существующий текстовый слой, ссылки и
электронная подпись не переносятся. Исходный PDF сохраняется. Не заменяйте им
электронно подписанный оригинал.

## OCR для контроля (по желанию)

Установите отдельно Tesseract и языковые данные `rus`, `eng`:

```bash
python ocr_audit.py output/run_001/ИМЯ_ДОКУМЕНТА__HASH --lang rus+eng --output ocr_run_001.json
```

OCR записывает распознанные слова, координаты и confidence, не меняет изображение.
Увеличение confidence не означает, что символы правильные. Для оценки нужны
ручная транскрипция и CER/WER; подписи не оценивают как печатный текст.

## Проверки и развитие

```bash
python -m unittest discover -v
```

Проверены пакет из четырёх форматов, повреждённый файл, неизменность оригиналов,
ручные/цветовые маски, совпадение пикселей внутри сохранённого PDF, слабые линии
на неравномерном фоне, пустые и маленькие изображения, ограничения параметров.
CI запускает те же тесты на Windows и Ubuntu. Локальные проверки проведены в Linux;
GUI и установка на конкретном Windows ПК ещё требуют проверки.

- [Методика и ограничения CV](docs/CV_METHODS.md)
- [План нейросетевого восстановления и критерии приёмки](docs/AI_ROADMAP.md)
- [Проверки версии 2](docs/VALIDATION.md)

## Усиление тусклых контуров (версия 2.1)

```bash
python enhance_batch.py input --output output/trace_001 --trace-study --trace-strength 0.8
```

Дополнительный `enhanced_trace_study.pdf` усиливает наблюдаемые штрихи с учётом
их направленной структуры. Это изменение пикселей, а не буквальная векторная
обводка и не распознавание подписи. Цветные печати здесь тоже обрабатываются.
`--trace-strength` допускает 0.25..2; большое значение может сливать линии.
Для точного сохранения областей добавьте `--regions protected_regions.json`: ручные
прямоугольники остаются неизменными и в этом режиме.

Модель не копирует рамку с одной стороны на остальные и не соединяет отсутствующие
штрихи. Наличие узора справа не доказывает его форму слева. Проверяйте подписи,
цифры и мелкие буквы по исходнику; более тёмный штрих не означает восстановленный.
Для тестов: `python -m unittest discover -v` (12 тестов, включая белый разрыв линии).

Метод: [наблюдаемые контуры](docs/TRACE_METHOD.md).
